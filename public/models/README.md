# World assets

The room, furniture, miniature project displays, plants, companion, materials and screen textures are original procedural work generated in the browser. Ambient rain and interaction sounds are synthesized locally using Web Audio; no third-party audio is used.

`duck.glb`: Duck, copyright 2006 Sony, distributed by Khronos glTF Sample Assets. Original model is unchanged; positioned and scaled at runtime. SCEA Shared Source License 1.0, included as SCEA-LICENSE.txt.
Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Duck

The optional duck loads after the main room and has a procedural substitute if unavailable.
